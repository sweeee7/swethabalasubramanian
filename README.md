# Swetha Balasubramanian 

A static portfolio site (plain HTML, CSS and JS, no build step) for GitHub Pages.

## Put it online

1. Create a repository on GitHub named `swetha-bala02.github.io` (use your GitHub username: `<username>.github.io`), or any name for a project site.
2. Upload everything in this folder (`index.html`, `assets/`, `img/`, `.nojekyll`) to the repository root.
3. In the repository, open Settings, then Pages, then set the source to the `main` branch, root folder.
4. The site appears at `https://<username>.github.io/` after about a minute.

## Notes

- The cover animation (`assets/flow.gif`) is an illustrative 2D lattice Boltzmann simulation of flow past a flipper-like body with a scalloped leading edge. It is not data from the MSc thesis.
- Project pages use hash links (`#crm`, `#saccon`), so they work on GitHub Pages with no extra set-up.
